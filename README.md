Made my first HTML project : Online Examination Portal
📝 Online Examination Portal

A simple and beginner-friendly Online Examination Portal built using HTML5. This project is my first step into web development, created to apply my HTML knowledge through a practical project.

🌟 About the Project

The Online Examination Portal provides a basic examination interface where students can enter their details and attempt different types of questions.

✨ Features

- Student information form
- Student name, roll number and email fields
- Branch and subject selection
- Multiple Choice Questions (MCQs)
- True/False questions
- Short-answer questions
- Submit and Reset buttons
- Simple and easy-to-use interface

🛠️ Technologies Used

- HTML – To create the structure and content of the website.

🎯 What I Learned

While building this project, I practised:

- HTML document structure
- Forms and input elements
- Radio buttons and dropdown menus
- Text areas and buttons
- Organizing webpage content

🚀 Future Improvements

I plan to improve this project as I continue learning web development:

- Add CSS for better styling and layout.
- Use JavaScript for form validation and automatic result calculation.
- Add a more interactive examination experience.
- Explore backend integration in the future.

💻 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
